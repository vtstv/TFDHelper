# TFDHelper

**Automation script for The First Descendant**

## ⚠️ Disclaimer

This tool is for personal use and convenience. Please ensure compliance with game terms of service.

**This script does not contain any serious cheat functions** - only quality of life (QoL) automation features to reduce repetitive actions and improve gameplay comfort.

## 📥 Installation

1. Install [AutoHotkey v2](https://www.autohotkey.com/v2/)
2. Download or clone this repository
3. Run `TFDHelper.ahk` or compile with `build.ps1`
4. Configuration file `TFDHelper.ini` will be created automatically

## 🎮 Quick Start

### Core Controls
- **Numpad0** - Master toggle (on/off all modules)
- **Numpad8** - Show status

### Character Modules (mutually exclusive)
| Key | Character | Description |
|-----|-----------|-------------|
| Numpad2 | Bunny | Auto movement + jumping (F4, R, V, F5) |
| Numpad3 | Luna | Skill combo (E key) |
| Numpad4 | Viessa | Skill 4 single click (4/Z keys) |
| Numpad5 | Freyna | Auto C/V (F3 toggle, C/V pause) |
| Numpad9 | Hailey | Auto Q (Q to pause) |

### Utility Modules
| Key | Module | Description |
|-----|--------|-------------|
| Numpad1 | Tabber | Auto tab press |
| Numpad6 | Quest Abort | ESC sequence (T key) |
| Numpad7 | Repeat | F2+R sequence (T key) |
| F6 | Ascend (Auto refill ammo using Ascend set) | Auto sequences (LClick, R, E) |

## ⚙️ Configuration

Edit `TFDHelper.ini` to customize timers and settings. All values in milliseconds.

- See `TFDHelper.ini.example` for all options
